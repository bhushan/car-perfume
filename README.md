# VELOURE — Parfums d'Automobile

Premium D2C website for a luxury car perfume brand. Dark-theme minimal luxury, cinematic animations, real-time 3D hero bottle.

## Stack

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS (design tokens in `globals.css`)
- Framer Motion (reveals, modals, sliders, micro-interactions)
- GSAP + ScrollTrigger (pinned horizontal gallery, velocity skew, magnetic buttons, cursor)
- Lenis (inertia smooth scrolling)
- Three.js (hero bottle: glass transmission material, orbiting studio lights, mouse parallax)
- Zustand (cart / wishlist / quick view / recently viewed)

## Run

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

## Structure

- `src/app` — layout (self-hosted fonts), page composition, theme tokens
- `src/components/sections` — Header, Hero, BrandStory, Collection, ScentNotes, WhyUs, Lifestyle, Testimonials, Comparison, Instagram, FAQ, Newsletter, Footer
- `src/components/shop` — CartDrawer (sticky floating cart), QuickView, ExitIntent, RecentlyViewed
- `src/components/fx` — SmoothScroll, Preloader, Cursor, Particles, MagneticButton, Reveal/MaskLines, TiltCard, Counter
- `src/components/three/BottleScene.tsx` — hero 3D bottle
- `src/lib/data.ts` — products, notes, testimonials, FAQs (single source of truth for copy)
- `public/images` — product renders and lifestyle scenes (generated by `scripts/shoot.mjs` from `scripts/render/index.html`; replace with real photography by keeping the same filenames)

## Imagery pipeline

`node scripts/shoot.mjs` re-renders every product/lifestyle image headlessly (Chromium + Three.js/canvas). Swap in real photos anytime; all references live in `src/lib/data.ts`.

## Notes

- All animations honor `prefers-reduced-motion`.
- Checkout button is UI-only; wire Stripe/Razorpay in `CartDrawer`.
- Newsletter form validates locally; connect ESP in `Newsletter.tsx`.
